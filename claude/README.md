# claude/

Working notes from Claude's GUI redesign, kept here so the work can be handed to another agent.

- `docs/HANDOFF.md`: start here. What was asked, what's done, what's left, the contracts not to break.
- `docs/UI_KIT.md`: the design-language kit (painter, styles, theme, controls).
- `docs/TESTING.md`: previews, theme rebuild, validators and their last known results.
- `docs/screenshots/`: renders of finished phase-1 screens (`done_*`) and phase-2 work in progress (`wip_*`).
- `wip/`: phase-2 files, mirrored at their project paths. They are not live yet; see HANDOFF section 3.

The `.gdignore` file keeps Godot from importing anything in this folder.
