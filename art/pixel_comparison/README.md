# Pixel-art style comparison

These are pixel-art alternatives for comparing against the illustrated concepts:

- `thura_walk_4dir_pixel.png` — pixel-art interpretation of Thura's 4×4 directional movement reference, based on the canonical star-marked character.
- `asteria_return_ship_pixel.png` — pixel-art interpretation of the Asteria room layout, preserving its main room arrangement and landmarks.

Both are visual concepts, not production assets. The character sheet needs per-cell alignment cleanup before Godot import; the ship image is a complete map concept rather than a reusable tile set.
